# Terminal Quiz Game

## About
This is a simple Python quiz game that runs in the terminal. It asks multiple-choice questions and checks the player's answers.

I created this project to practice my Python programming skills.

## Features
- Asks the player's name.
- Displays multiple-choice questions.
- Checks answers automatically.
- Keeps track of the score.
- Displays the final result.

## Requirements
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project folder in the terminal.
3. Run the following command:

bash
python quiz_game.py
